# Tell a Whole Story in 32 Characters

A make.fun entry for [Tell a Whole Story in 32 Characters](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978): a program that writes a single Wi-Fi network name of at most 32 characters to `/output/entry.txt`.

The entry: **Dad Found My Search History** (27 characters) — a household confession as a network name. Dad found the search history; the reader instantly pictures the kid, the awkward conversation, and the grounded aftermath.

Run it with Python 3.13:

```sh
python3 main.py
```
